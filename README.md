# Ardian Bagus Surya — Portfolio

My personal portfolio site: a place for people to see my work in communication, social media, and campaigns. I built it myself with AI assistance, as a non-engineer.

**Live site:** https://ardianbagusan.github.io/Portofolio/

![Portfolio home](screenshots/home.png)

## What's on it

- About me and my background in communication
- Project case studies: campaigns, webinars, and content work

## Why I built it

I wanted one place to show my work to recruiters and collaborators, in a form I control.

## Built with

- HTML
- Hosted on GitHub Pages
- Built with AI assistance: Claude (vibe coding)

## How I built it

- **What I did:** Defined the structure and architecture, made the mockups, wrote the writing guide, set the points the site needs to deliver, and assessed the UX and UI at a surface level.
- **What AI did:** Revised the code, partially wrote the code, and fixed picture issues.
- **What I learned:** How HTML works, how UI and UX work, and how to take code through to a finished, deployed product on GitHub.
